## 🎯 Проблема

Традиционные SIEM-системы полагаются на **детектирование по сигнатурам** — они могут найти только те угрозы, о которых уже знают. Этот подход пропускает:

- ✗ Инсайдерские угрозы с валидными учётными данными
- ✗ Lateral movement APT с легитимными инструментами
- ✗ Медленную эксфильтрацию данных
- ✗ Паттерны эксплуатации zero-day уязвимостей
- ✗ Атаки Living-off-the-Land (LOLBins)

**LogHunter-AI** использует **машинное обучение без учителя** для обнаружения поведенческих аномалий — выявляя «неизвестные неизвестные», которые обходят традиционные правила.

## ⚡ Быстрый старт

### 1. Клонирование и настройка

```bash
git clone https://github.com/ranas-mukminov/LogHunter-AI.git
cd LogHunter-AI
```

### 2. Запуск сервисов

```bash
docker-compose up -d
```

### 3. Проверка

```bash
curl http://localhost:8000/health
```

Готово! LogHunter-AI запущен и готов принимать логи.
